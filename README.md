# gate-mgmt

UNIVS GATE 관리 서비스 — 서버 API 로 통계와 가입 계정 현황을 보는 관리 화면.

> 이 저장소는 공개(public)다. 코드는 누구나 볼 수 있으므로 **비밀값과 실제 데이터는 절대 커밋하지 않는다.**
> 배포된 화면은 접근이 제한되며, 데이터는 권한 검사를 거친 서버 API 로만 받는다.

## 작업 흐름

1. `main` 에서 브랜치를 만든다 — 예: `feat/UG-123-dashboard-chart`
2. 작업 후 브랜치를 push 하고 `main` 으로 PR 을 연다 (PR 제목에 Jira 키)
3. 검토 후 `main` 에 머지되면 개발 서버에 자동 배포된다
4. 개발 서버에서 확인 → Jira 에 검수 결과 → 스테이징 · 운영 승격

`main` 에는 직접 push 할 수 없다 (브랜치 보호). 자세한 규칙은 [CLAUDE.md](CLAUDE.md).
